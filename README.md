# SecureMessenger – پیام‌رسان امن دوزبانه

نسخه نهایی قابل اجرا طبق تمام قوانین سخت‌گیرانه پروژه.

## هدف
پیام‌رسان شبیه تلگرام با ثبت‌نام و ورود اصلی از طریق **شماره موبایل + کد پیامک**، Google Authenticator **اختیاری** برای تأیید دو مرحله‌ای، محدودیت حداکثر ۳ اکانت به ازای هر دستگاه، Soft Delete کامل، Polling (بدون WebSocket)، Backend Flask + MySQL سازگار با cPanel، و پنل ادمین وب مخفی.

## ویژگی‌های پیاده‌سازی‌شده
- ثبت‌نام با ایمیل/رمز/شماره موبایل و ورود اصلی به‌سبک تلگرام با کد یک‌بارمصرف SMS؛ Google Authenticator اختیاری (QR + کلید یک‌بارنمایش)
- محدودیت **حداکثر ۳ اکانت** روی هر دستگاه (Fingerprint پایدار)
- چت خصوصی، گروه، کانال، پشتیبانی، **Saved Messages**
- ارسال متن، عکس، ویدیو، **ویس‌مسیج (انتخاب فایل صوتی)**
- ریپلای، فوروارد، پین، View Once
- وضعیت خوانده‌شده / سین / آنلاین / گوست مود
- حذف یک‌طرفه و دوطرفه پیام و تاریخچه و کل چت (Soft Delete + Audit)
- جستجوی کاربر + جستجو داخل چت
- تم روشن/تاریک/سیستم + زبان فارسی/انگلیسی
- بک‌گراند سفارشی هر چت
- پروفایل (عکس، نام، یوزرنیم، بایو)
- پنل ادمین وب با مسیر مخفی (`/sm-admin-x9k2p7/`)
- Polling هر ۳ ثانیه (هیچ WebSocket)
- همه چیز در دیتابیس ثبت می‌شود و hard-delete نمی‌شود

## راه‌اندازی Backend (cPanel / لوکال)
```bash
cd backend
python3 -m venv venv
source venv/bin/activate   # Windows: venv\Scripts\activate
pip install -r requirements.txt
cp .env.example .env
# DATABASE_URL و SECRET_KEY و ADMIN_PASSWORD را پر کنید
python run.py
```
- پیش‌فرض: `http://0.0.0.0:5000`
- Health: `GET /health`
- Admin: `http://localhost:5000/sm-admin-x9k2p7/login`

## راه‌اندازی Flutter
1. در `lib/core/constants/api_constants.dart` مقدار `baseUrl` را تنظیم کنید:
   - امولاتور: `http://10.0.2.2:5000/api/v1`
   - دستگاه واقعی: IP سرور خودتان
2. آیکون: یک فایل PNG با کیفیت در `assets/icons/app_icon.png` قرار دهید و:
   ```bash
   dart run flutter_launcher_icons
   ```
3. فونت Vazirmatn (اختیاری): فایل‌های ttf را در `assets/fonts/` بگذارید یا از google_fonts استفاده می‌شود.
4. اجرا:
   ```bash
   flutter pub get
   flutter run
   ```

## تصمیمات مهم (ضد Amnesia)
1. هیچ WebSocket / SocketIO استفاده نشده – فقط HTTP Polling.
2. Soft Delete همه‌جا + جدول `audit_logs`.
3. کد پیامک فقط در سرور هش و با TTL/محدودیت ارسال نگهداری می‌شود؛ 2FA با `pyotp` اختیاری و با تأیید صریح کاربر فعال می‌شود.
4. محدودیت ۳ دستگاه با fingerprint پایدار (حتی بعد از uninstall).
5. `minifyEnabled = false` در release.
6. نام‌گذاری ضدتداخل.
7. فقط `flutter_riverpod` (بدون generator).
8. Theme فقط فرم‌های مدرن `*ThemeData`.
9. پنل ادمین مسیر مخفی.
10. بدون دسترسی مخاطبین.

## ورود به پنل ادمین

1. Backend را اجرا کنید: `python run.py`
2. در مرورگر بروید به:
   ```
   http://localhost:5000/sm-admin-x9k2p7/login
   ```
   (مسیر مخفی از `.env` → `ADMIN_SECRET_PATH`)
3. نام کاربری و رمز از `.env`:
   - `ADMIN_USERNAME` (پیش‌فرض: superadmin)
   - `ADMIN_PASSWORD` (پیش‌فرض: ChangeThisStrongPassword123!)

## اصلاحات چت و چنداکانت (۷ سپتامبر ۲۰۲۶)

- همگام‌سازی حذف پیام‌های خوانده‌شده و دریافت‌شده در چت باز، با همان polling سه‌ثانیه‌ای و بدون WebSocket.
- عکس پروفایل و وضعیت آنلاین/آخرین بازدید در هدر، حتی پیش از اولین پیام.
- کپی متن پیام و کپشن از منوی نگه‌داشتن پیام، با حفظ محدودیت پیام یک‌بارمصرف.
- اصلاح مسیر افزودن اکانت و ورود/ثبت‌نام/2FA تا لیست چت‌ها، همراه با جداسازی نشست‌ها.
- پیش‌نمایش، عضویت و ورود به گروه/کانال با لمس لینک دعوت در پیام و امکان کپی لینک.

نیازی به مهاجرت دیتابیس یا تغییر نسخه وابستگی‌ها نیست؛ ابتدا بک‌اند و سپس کلاینت را به‌روزرسانی کنید.
جزئیات، سازگاری لینک‌های قدیمی، نتیجه تست‌ها و چک‌لیست دو دستگاه:
[Chat polling, accounts and invitations](docs/chat-polling-account-invite-fixes.md).

## گروه، کانال، حریم خصوصی عضویت و زمان پیام‌ها (۸ سپتامبر ۲۰۲۶)

- افزودن عضو پس از ساخت گروه/کانال از صفحه اطلاعات؛ نتایج جستجو و کاربران با محدودیت عضویت فقط لینک دعوت دریافت می‌کنند.
- گزینه **Allow people to join / اجازه افزودن به گروه و کانال** در تنظیمات، زیر حالت گوست.
- دسترسی‌های واقعی گروه و دسترسی جداگانه هر مدیر برای پیام، عکس، عکس یک‌بارمصرف، ویدیو، ویس، فایل، دعوت و مدیریت؛ اعمال دسترسی در سرور، حتی برای فوروارد.
- تفکیک رابط گروه از کانال انتشار؛ مشترکان کانال امکان ارسال ندارند و پست‌ها با هویت کانال نمایش داده می‌شوند.
- امکان حذف کامل عکس فعال پروفایل و بازگشت به حروف اولیه، بدون حذف حساب.
- اصلاح تفسیر UTC در کلاینت و نمایش ساعت/تاریخ صحیح در فهرست چت‌ها.

**این نسخه برای دیتابیس‌های قبلی به ارتقای افزایشی نیاز دارد.** پس از پشتیبان‌گیری و توقف workerها، پیش از اجرای بک‌اند جدید و انتشار کلاینت:

```bash
cd backend
python -m flask --app run:app upgrade-chat-schema
```

`db.create_all()` به‌تنهایی جدول‌های موجود را ارتقا نمی‌دهد. نسخه پکیج‌ها تغییر نکرده است.
تست‌های بک‌اند: **۱۲۶ تست موفق**؛ تست اجرایی Flutter و ساخت APK در این محیط به علت نبود SDK انجام نشده است.

راهنمای کامل، مرزهای رفتار شبیه تلگرام، API، مهاجرت و چک‌لیست دو دستگاه:
[Groups, channels, permissions and timestamps](docs/group-channel-permissions.md).

## آرشیو، پوشه‌ها، سنجاق، آلبوم پروفایل و ویدیو (۸ سپتامبر ۲۰۲۶)

- آرشیو چت‌ها از فهرست (نگه‌داشتن چت) به‌همراه ردیف «Archived chats» و **رمز چهاررقمی آرشیو** در تنظیمات.
- سنجاق **چند پیام** در چت خصوصی، گروه و کانال با نوار سنجاق و فهرست کامل پیام‌های سنجاق‌شده.
- سنجاق چند چت در بالای فهرست.
- پوشه‌ها مثل تلگرام: دو پوشه پیش‌فرض «All» و «Personal» به‌علاوه پوشه‌های دلخواه با انتخاب آزاد کانال/گروه/افراد.
- تنظیم عکس گروه و کانال، و **چند عکس پروفایل** برای کاربران با نمایش تمام‌صفحه و swipe.
- «حذف تاریخچه برای همه» همیشه برای مالک گروه/کانال فعال است.
- اصلاح ذخیره‌نشدن بایو.
- «جستجوهای اخیر» در تب جستجو برای دسترسی دوباره به کاربران پیداشده.
- پخش ویدیو مثل تلگرام: پخش = ورود خودکار به تمام‌صفحه، خروج = توقف خودکار پخش.

**این نسخه به ارتقای افزایشی دیتابیس نیاز دارد:**

```bash
cd backend
python -m flask --app run:app upgrade-chat-schema
```

تست‌های بک‌اند (پس از به‌روزرسانی ورود SMS): **۱۵۵ تست موفق**. جزئیات کامل، API و چک‌لیست:
[Archive, folders, pins, profile album and video](docs/archive-folders-pins-profile.md).

## ورود با شماره موبایل و SMS.ir (۱۲ سپتامبر ۲۰۲۶)

ثبت‌نام جدید با شماره موبایل انجام می‌شود و Google Authenticator دیگر صفحه
اجباری پس از ثبت‌نام نیست؛ کاربر در صورت تمایل آن را در تنظیمات فعال می‌کند.
تنظیمات امن backend، مهاجرت افزایشی دیتابیس، حالت تست محلی و سیاست‌های TTL/rate
limit در [راهنمای SMS.ir و phone auth](docs/phone-auth-sms-ir.md) آمده‌اند.
